Disco 是一款用于分析和清理磁盘、彻底卸载程序的桌面应用。它是 harry0703 的 [MangoDisk](https://github.com/harry0703/MangoDisk) 的分支，并正在逐步整合 Marcin Szeniak 的 [Bulk Crap Uninstaller](https://github.com/Klocman/Bulk-Crap-Uninstaller)（BCU）的卸载功能。

**状态：** 早期开发阶段，优先支持 Windows；尚无正式发布版本，请从源码构建。

完整说明（功能、命令行 `disco clean`、从源码构建）请参阅 [English README](README.md)。

Disco 与 MangoDisk、BCU 无隶属关系，也未获其认可。许可证：GPL-3.0-only。归属信息见 [`NOTICE`](NOTICE)。
