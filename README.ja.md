Disco は、ディスクの分析とクリーンアップ、プログラムの徹底的なアンインストールを行うデスクトップアプリです。harry0703 による [MangoDisk](https://github.com/harry0703/MangoDisk) のフォークで、Marcin Szeniak による [Bulk Crap Uninstaller](https://github.com/Klocman/Bulk-Crap-Uninstaller)（BCU）のアンインストール機能を段階的に統合しています。

**状況：** 開発初期段階です。Windows を優先しています。正式リリースはまだないため、ソースからビルドしてください。

機能、コマンドライン（`disco clean`）、ソースからのビルドの詳細は [English README](README.md) を参照してください。

Disco は MangoDisk および BCU と提携しておらず、承認も受けていません。ライセンス：GPL-3.0-only。帰属表示は [`NOTICE`](NOTICE) を参照してください。
