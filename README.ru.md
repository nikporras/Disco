Disco — настольное приложение для анализа и очистки диска и полного удаления программ. Это форк [MangoDisk](https://github.com/harry0703/MangoDisk) автора harry0703, в который постепенно добавляются функции удаления программ из [Bulk Crap Uninstaller](https://github.com/Klocman/Bulk-Crap-Uninstaller) (BCU) Марцина Шеняка.

**Статус:** ранняя стадия разработки, в первую очередь Windows. Официальных выпусков пока нет — соберите приложение из исходного кода.

Подробности о возможностях, командной строке (`disco clean`) и сборке из исходного кода — в [English README](README.md).

Disco не связан с MangoDisk и BCU и не одобрен ими. Лицензия: GPL-3.0-only. Сведения об авторстве — в [`NOTICE`](NOTICE).
