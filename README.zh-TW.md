Disco 是一款用於分析和清理磁碟、徹底解除安裝程式的桌面應用程式。它是 harry0703 的 [MangoDisk](https://github.com/harry0703/MangoDisk) 的分支，並正逐步整合 Marcin Szeniak 的 [Bulk Crap Uninstaller](https://github.com/Klocman/Bulk-Crap-Uninstaller)（BCU）的解除安裝功能。

**狀態：** 早期開發階段，優先支援 Windows；尚無正式發行版本，請從原始碼建置。

完整說明（功能、命令列 `disco clean`、從原始碼建置）請參閱 [English README](README.md)。

Disco 與 MangoDisk、BCU 無隸屬關係，也未獲其認可。授權條款：GPL-3.0-only。歸屬資訊見 [`NOTICE`](NOTICE)。
